# AI Engineering Portfolio

Personal website showcasing my work and development as an AI engineer.

## Overview

A personal portfolio and blog documenting projects, experiments and insights focused on **LLM-powered applications and evals**.

The site is designed to showcase not only finished projects, but also the thinking, experimentation and technical decisions behind them.

## Features

* 🏠 **Portfolio homepage** — A landing page with links to the about and blog pages.
* 👤 **About** — Background, experience and technical interests.
* ✍️ **Blog** — Articles documenting projects, experiments and insights.
* 📱 **Responsive design** — Designed for both desktop and mobile. 

## Tech Stack

**Frontend:** HTML · CSS · JavaScript

## Purpose

The website serves as a living portfolio of my transition into AI engineering, with an emphasis on **building practical LLM-powered systems and evals**.

Rather than presenting projects as isolated demonstrations, the blog provides context around the problems they address, the approaches explored and the lessons learned.

## Development

The site is developed alongside the projects and writing it showcases. Its structure and content will evolve as my work and technical interests develop.
