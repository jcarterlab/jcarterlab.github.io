💼 What I do

I’m an AI application engineer specialising in using Python to build LLM-powered systems that solve real-world business problems. I build lightweight, cost-efficient tools using Gradio and Hugging Face, as well as scalable applications using Next.js and Google Cloud Platform.



💻 Tech stack

  • Backend: FastAPI

  • Version control: Git, GitHub
  • DevOps: Docker, GCP

⚙️ Engineering practices

  • Observability: Logging
  • Reliability: Error handling, retries, timeouts
  • Quality: Unit testing, debugging
  • Architecture: Modular design
  • Performance: Cost optimisation


🌱 Personal journey

My interest in exploring technical solutions first began in 2018 when I used Tableau to visualise the changing spatial distribution of Chinese innovation for my masters thesis while studying "Political Economy of Emerging Markets" at King's College London.

After developing an interest in China's growing tech capabilities (I am still amazed by WeChat Pay), I spent a year from 2019 to 2020 teaching English in Beijing. I then became stranded in Cambodia for 4 months during the initial wave of Covid-19 in 2020 while travelling the region. Faced with newly acquired free time, I decided to learn the R programming language for data analysis.

But I soon realised I'd caught the travel bug and proceeded to spend the next several years touring Europe, the Middle East and Latin America as a freelance academic editor on Upwork. This exposed me to academic research in machine learning, which sparked my initial interest in AI.

Some of my travel photos.

Along the way, I also realised how rewarding it was to move beyond data analysis to create real tools others can use by making a low-code Retool database app for a Turkey-based NGO in 2022. This newfound sense of accomplishment was reinforced in 2024 when I became the duty manager of a London-based hostel and built various productivity tools in Excel, such as a group booking quote generator.

I then deepened my software engineering skills through freelance microapp development for Mosaique Creative’s corporate intranet clients in 2025. These newly acquired skills allowed me to combine my passion for making tools with my interest in AI to build LLM-powered apps, including monitoring pipelines, retrieval augmented generation (RAG) systems and agent workflows.
