What I do

I’m an AI engineer specialising in using Python to build LLM-powered tools that solve real business problems. I can build cost-efficient solutions using Gradio and Hugging Face as well as more scalable solutions using next.js and Google Cloud Platform. Past projects of mine include agents, retrieval augmented generation (RAG) systems, news monitoring pipelines, LLM evaluations and more.




Technologies

Python · FastAPI · Next.js · Docker · GCP · GitHub · Gradio · Hugging Face




How I got into tech

My technical experience began during a Political Economy of Emerging Markets master's degree at King's College London in 2018. I used Tableau to visualise the changing spatial dynamics of Chinese innovation. After developing an interest in China's growing tech capabilities (I am still amazed by WeChat Pay), I spent a year teaching English in Beijing from 2019 to 2020. I then decided to learn the R programming language after becoming stuck travelling in Cambodia at the onset of the Covid-19 pandemic. I soon realised I'd caught the travel bug and spent the next few years travelling Europe, the Middle East and Latin America as an online freelance academic editor. This work exposed me to academic research on data science and machine learning, peaking my interest in AI.

While on the road, I set up a Retool database app for an NGO in Turkey and created a Power BI data visualisation dashboard for political risk consultancy in Colombia. After returning home to the UK, I created a chatbot using retrieval augmented generation (RAG) to answer staff questions while duty manager of a London hostel. I then began collaborating with the LumApps intranet implementation team at Mosaique Creative to build microapp integrations for their corporate clients.

Now, I build LLM-powered tools that help businesses optimise processes and create value. If you'd like to learn more about my work, you can explore the links below. My blog shares high-level overviews of projects, experiments and insights, while my GitHub showcases the code behind it all. And of course, don't forget to reach out by sending a message via email or on LinkedIn!
