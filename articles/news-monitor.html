Getting LLMs to decide which news stories they summarise





Project

June 16th, 2026

---

NewsMonitor is a news monitoring tool designed to analyse large volumes of news at a relatively low cost using the Google Gemini API. This is made possible by giving the LLM scraped headlines from various news sources and asking it to choose which stories should be scraped and summarised based on a certain monitoring objective (e.g. political risk in Colombia or tech investment opportunities in London).

The process is made more efficient by using a database of previously processed headlines to immediately discard old stories. This allows the user to do more frequent runs (daily or even hourly) without having to worry about the extra LLM costs associated with processing the same stories twice.

Once all the story texts are collected, thousands (or even hundreds of thousands) of words are split and summarised in batches by a weaker LLM (gemini-2.5-flash). A stronger LLM (gemini-2.5-pro) is then used to create a final summary from these batched summaries. This ensures that the final content more closely aligns with the monitoring and formatting objectives in a cost optimised way.

The final summary is then stored in a database and optionally emailed to a recipient or a list of recipients. This allows runs to be scheduled either locally via a something like a cron job or in the cloud through a cloud scheduling system. The user is left with a fully automated pipeline that lets them track performance via logging, add/remove sources and adjust their monitoring objectives over time.
